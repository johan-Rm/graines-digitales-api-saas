# Checklist de review

- Le scope correspond a la tache.
- Aucun secret n'est committe.
- Les routes projet restent protegees par membership.
- Les migrations preservent les donnees si necessaire.
- Les payloads restent compatibles ou le breaking change est documente.
- Les tests couvrent les comportements critiques touches.
- La documentation proprietaire est mise a jour sans duplication.
