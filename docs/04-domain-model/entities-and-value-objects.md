# Entites et objets valeur

Entites principales actuelles :

- `Organization`
- `Project`
- `ProjectMember`
- `User`
- `MediaObject`
- `Accommodation`
- `AccommodationMedia`
- `PropertyValue`
- `WebPage`
- `Article`
- `CreativeWork`
- `MenuItem`
- `CategoryCode`
- `Message`

Les identifiants domaine sont des UUID.

`PropertyValue.name` utilise le referentiel ferme `AccommodationQuality` :
`Confort`, `Architecture`, `Intérieur`.
