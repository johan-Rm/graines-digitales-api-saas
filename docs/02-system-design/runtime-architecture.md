# Architecture runtime

- Runtime cible : PHP 8.4.
- Framework : Symfony 8.
- Exposition HTTP : API Platform.
- Base de donnees : PostgreSQL.
- ORM : Doctrine ORM.
- Execution locale : Docker Compose.

Le backend est une API headless SaaS pour contenus multi-organisations et
multi-projets. Les webapps clientes consomment l'API via des contrats explicites.
